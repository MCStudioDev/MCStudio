### Remote Repository Setup

To connect this local repository to a remote GitHub repository:

1. Create a new repository on GitHub (don't initialize with README)
2. Add the remote origin:
   ```bash
   git remote add origin https://github.com/yourusername/mina-energy-consulting.git
   ```
3. Push to remote repository:
   ```bash
   git branch -M main
   git push -u origin main
   ```
